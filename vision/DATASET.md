# 第一批摄影素材与人工审核

本轮先建立约 200 张可追溯的真实照片候选，自动草标后交给用户审核；不自动训练模型、不把机器标注当作人类意见。

## 第一批的来源与用途

素材从 Wikimedia Commons 的精选照片分类抽样，人像候选与风光候选各 100 张。社区精选只是筛选依据，不表示每张照片都适合手机辅助摄影，或原图一定优于其他取景。

每张记录原始文件页、下载 URL、作者、许可名称/链接、来源另列限制、原图尺寸、预览图尺寸、下载时间、SHA-256 和精选依据。下载的是 Commons 生成的最长边约 1280px 预览衍生图；下载字节原样保存，不冒充原始相机文件。精确重复和近似重复在收集阶段过滤；每个署名作者最多保留 10 张。作者署名规范化不完美，不同署名形式仍需复核。

使用逐张允许的 CC BY、CC BY-SA、CC0 或公有领域记录，不把整批图片重新声明为统一许可。保留各文件署名与 ShareAlike 条件。肖像等额外使用条件单独记录；当前仅为本地审核候选，尚未完成最终训练数据准入。Commons 的说明见 [内容重用](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)。

自动筛选后还检查了全部缩略图，替换混入的非照片版式与非人像内容，保留筛选记录。历史黑白肖像、舞台、体育、劳动和多人纪实画面仍可能出现；可在审核中按 App 的实际用途排除。

## 标注含义

| 内容 | 如何产生 | 审核时注意 |
| --- | --- | --- |
| 人物/物体/地标框、背景类别 | 本地 Qwen3-VL 预训练模型 + JSON 约束 + 坐标校验 | 仍会漏检、误检，尤其是多人、遮挡、远景 |
| 主体位置、占比、框到边缘的距离 | 根据模型框计算 | 框内未必包含所有手脚，不是独立精确测量 |
| 显示图亮度统计 | 128×128 灰度直方图 | 不能据此标注 RAW 过曝、真实照度或真实光源方向 |
| 两套取景及观察提示 | 已有原创摄影规则与教程索引 | 没有自动优劣标签，不能当作摄影师的实际意图 |
| 动作、表情方向、光线、拍摄意图 | 留给人工补充 | 未知可留空，不推断真实情绪或现场未见的信息 |
| A/B 偏好与理由 | 用户审核 | 模型不替用户投票，原图不自动作为正样本 |

教程仅使用公开教学内容的原创概括，带来源 ID：Nikon 的背景/取景/动作比较，以及 Scott Kelby 在 Rocky Nook 的公开风光节选。没有下载教材配图、复制书籍全文，或把整本书宣称为已训练知识。

## 如何审核

打开本地 `vision/data/batches/batch-001/review.html`，无需账号或服务器。

1. 逐张看照片与主体框，选择「保留为素材」或「排除这张」。
2. 判断主体和背景标注是否可接受；错误可写入备注，也可在高级 JSON 编辑区修正并应用。
3. 点击 A/B 按钮显示参考裁剪框，再选择偏好、都可以或都不合适。A/B 的方案名称会随人像/风光意图变化，以页面实际显示为准。
4. 能确认时补充姿态、表达方向、光线和拍摄意图；无法确认就留空。
5. 定期点「导出审核结果」，保存 JSON。后续可导入该文件继续审核，完成后交回 JSON 即可。

浏览器本地进度只是便利缓存，可能因切换浏览器、清理数据或本地文件存储策略丢失，导出的 JSON 才是可交回的记录。无需一次审核完 200 张，可先看十几张反馈标注标准。

修正主体框后，页面会更新主体框；原有两套候选取景保持原样，便于审核这次机器给出的方案。备注可以要求后续重新生成方案，不能把旧候选误当成已经根据新框重算。

## 数据文件

- `manifest.json`：200 张照片的来源、许可、校验散列和初步划分。
- `images/`：下载的照片预览文件。
- `annotations/*.json`、`annotations.jsonl`：逐张机器草标、原始响应、耗时、依据与待核对项。
- `review.html`：完整离线审核页面，内嵌最长边 960px 的显示预览，可单独复制打开；不再依赖旁边的图片目录，没有照片上传或远程脚本。原始下载文件保留在 `images/`，校验散列不变。
- `batch-summary.json`：数量、类别、许可和工程异常汇总。
- `curation-history.json`：人工初筛替换记录；被替换的旧文件仅作为本地审计资料保存。

数据目录 `vision/data/batches/` 被 Git 忽略，照片及后续用户审核意见不会随代码提交公开仓库。

## 重复执行

下载阶段需要联网，推理与审核阶段使用本地文件。下载脚本只访问 Commons API 和官方图片域名，没有图库账号、付费 API 或用户照片上传。

```powershell
python vision/scripts/collect_dataset.py --count 200 --output vision/data/batches/batch-001
# 用已经安装视觉模型的 Python 环境执行，DLL 路径设置同 run-windows.ps1
python vision/scripts/annotate_dataset.py --batch-size 4
python vision/scripts/build_dataset_review.py
```

下载脚本建议使用新的批次目录。自动草标可恢复：已存在且图像散列、提示词散列一致的文件会跳过，文件不匹配则停止。四图批量推理在显存不足时退回单图；记录的是整批耗时，不能把它当成每张单独请求的耗时。

审核导入：

```powershell
python vision/scripts/import_dataset_review.py "D:/Downloads/framecoach-review-batch-001.json"
```

导入会校验整批 manifest、图像散列和标注散列，拒绝错批次、旧版本、重复 ID 或无效坐标。只整理用户明确保留且认可/修正的标签；仍不自动进行训练。批次初步按署名作者分组，最终划分还需核查同场景泄漏、内容分布与许可准入。
