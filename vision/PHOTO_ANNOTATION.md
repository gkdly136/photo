# 四维照片标注 v2

当前批次：200 张本地真实照片候选，来源、署名和许可沿用 `manifest.json`。旧 `review.html` 与 v1 标注保留，新入口是同目录 `review-v2.html`，所有照片预览仍内嵌，无需网络、服务器或同目录图片加载。

## 审核内容

| 维度 | 可编辑标签 | 判断边界 |
| --- | --- | --- |
| 神态 | 面部可见程度、眼神方向、嘴部状态、头部朝向 | 眼神左右按画面方向；不标人物内心情绪，过小或遮挡就标未知 |
| 构图类别 | 居中、三分、对称、对角线、引导线、框景、层次、留白、填满、重复、均衡；视觉重心与空间层次 | 最多选三个有依据的类别，不把每张图都套成三分；允许待确认 |
| 光影对比 | 明暗对比、整体调性、光质、推测来光、主体与背景明度关系 | 来光方向是待核验推测；灰度分位数只是显示图统计，不是现场光比或 RAW 曝光测量 |
| 姿态 | 可见程度、动作、躯干方向、手臂与双腿状态 | 只有上半身时降级未见腿部和不能确立的站坐动作；不是 ML Kit 实测骨架 |

本地推理分两步：整图分析构图与光影，再给选定人物的局部图分析神态与姿态；非人物主体的人物属性由范围规则标为不适用，不让模型编造人物。原始模型响应、所选主体框、模型固定版本、提示词散列、降级记录与显示图统计逐张保存。个别维度无效时只降级该维度，保留其他可验证输出。2B 模型仍会误标，尤其是方向、细小面部、姿态和构图类别；用户审核前都是草标，不能当作训练真值。

在全批检查中，直接分类的试验版出现大量重复“居中＋三分”，因此最终版先让模型描述画面证据再分类，旧试验记录仅保留作本地对照，不纳入交付包。对少量直接查看过原图的样例另有助手视觉复核说明，单独标明 `assistant_visual_check` 并保留复核前标签；这些仍是 AI 草标，不计为用户审核或人工真值，也不据此宣称整体准确率。

## 操作

1. 看左侧照片与主体框，选保留或不收入素材库。主体不对时在“核对主体”修正类型和 0–1000 坐标；这会重置四类审核并重建裁剪候选。
2. 在四类卡片内逐项核对。可选择“确认草标”“已人工修正”“确认不适用”或“退回重标”。修改属性会自动标记已人工修正；不适用仅用于非人物范围的神态与姿态。备注可以写判断依据。
3. 如果有兴趣比较构图，展开下方可选区。窗口实际裁剪显示，近似重复已过滤；可保留多个、微调坐标、选一个最喜欢的。没有足够不同窗口就不强行 A/B。原图不是自动正样本，候选不带审美分数。
4. “保存并下一张”保存当页；未完成的维度继续保持待审核。可按编号/作者搜索或筛选人像、风光与审核状态。
5. 定期导出 `framecoach-four-dimensions-review-v2.json`。浏览器本机缓存可能失效，导出文件可通过“恢复审核”导回。旧 v1 JSON 不冒充 v2 标签审核。

“退回重标”与“待审核”都不算该维度通过。保留且四类通过的照片才是人工核验候选；照片明确排除时审核进度计为完成，不替它生成四类认可。

## 文件与复现

- `analysis-v2-evidence-final/*.json` 和同名 `.jsonl`：版本化四维草标、模型原始输出和审计信息。
- `four-dimension-summary.json`：数量、格式异常和训练状态；不提供未经评测的准确率。
- `review-v2.html`：新的独立离线审核文件；原图下载文件与 v1 审核不修改。
- `human-review-v2/`：导入脚本核验后的人工记录，只存在本地，不会随 Git 上传。

使用已配置的视觉模型环境（Windows DLL 配置同 `scripts/run-windows.ps1`）：

```powershell
python vision/scripts/annotate_photo_dimensions.py --output-tag analysis-v2-evidence-final
python vision/scripts/build_photo_review.py
python vision/scripts/package_photo_review.py
python vision/scripts/import_photo_review.py --review "D:/Downloads/framecoach-four-dimensions-review-v2.json"
```

导入时独立校验 manifest、整批新标注摘要、每张照片与草标散列、四类枚举与审核状态、主体范围、裁剪包含关系与重复窗口、显式最优选择。不启动训练，不把草标或未选窗口当作人类意见。批次目录含照片及审核意见，继续被 Git 忽略。

SACD 参考与未取得其官方数据的情况见 [SACD_NOTES.md](SACD_NOTES.md)。本轮没有重新训练权重、没有修改 Android APK，也没有把桌面推理接到红米 K80。
