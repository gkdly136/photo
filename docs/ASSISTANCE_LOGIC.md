# 0.2 辅助逻辑与训练路线

2026-10-22，针对用户在 Redmi K80 上的反馈。K80 尚未接入开发环境，以下阈值是工程初值，不宣称已在该机型校准。

## 现在是怎样给建议的

1. CameraX 读取相机预览，最多每秒分析 5 帧。拍照另存原始 JPEG，不将辅助线写进原片。
2. 每帧采样 48 × 36 个亮度位置。稳定检测用每个位置附近 9 点均值，避免单像素边缘放大小幅手抖；亮度检查仍使用原始点。人像模式只比较图像边缘，以减少中央人物活动的干扰。边缘里的树叶、水面和人物仍可能干扰。
3. 对陀螺仪有正负方向的三轴速度先做约 160ms 时间常数的低通滤波，再计算幅度。旧版直接使用一次原始幅度，大于 0.09 rad/s 即清零，容易把手持震动当成重新取景。
4. 新版默认停留 2.5 秒，可选 2 / 2.5 / 3 秒。一般小幅波动继续计时；疑似移动先暂停累计，不抹掉已有进度。连续约 400ms 的明显移动才清零并撤下建议；极大的单帧画面改变立即撤下。缓慢持续转动也会重置。比较初始背景与当前背景，可发现累计的缓慢平移。
5. 稳定后，预训练的 ML Kit 人脸模型提供人脸框和头部转角；姿态模型提供关键点。本应用只使用肩、肘、腕、髋、膝、踝 12 点，忽略低于 0.65 或落在画面外的点。该值是关键点入画可能性，不是“姿态美观置信度”。
6. 摄影规则把测量结果与用户选择的构图、氛围组合起来，生成中文建议。没有训练摄影审美模型，也没有用用户照片在线学习。
7. 点击“立即辅助”可以对已经收到的画面直接请求建议；此时显示“已手动请求”，不声称画面稳定。后续真正移动仍会撤下旧建议。切后台、换模式、翻转镜头和恢复取景会重新观察。

稳定检测的工程阈值：相邻样本平均差 > 0.075、相对初始背景平均差 > 0.06、滤波后角速度 > 0.18rad/s，或者角速度 > 0.07rad/s 持续 800ms，进入疑似移动；持续 400ms 后确认。相邻样本差 > 0.22 立即确认。样本差会先消除整体曝光偏移。帧间断超过 1.5 秒重新计时；一次最多补计 400ms，避免卡顿被算成已经观察完成。这些不是通用物理定律，需要更多机型和真实场景验证。

## 每类建议实际知道什么

| 提示 | 输入与决策 | 能力边界 |
| --- | --- | --- |
| 人像构图 | 最大人脸的位置，相对所选三分或居中参考点的偏差 | 三分法是用户选择的方案，不是模型认为唯一最美位置。没有脸就不画目标圈；前景层次方案也不假造精确站位。 |
| 动作 | 双侧手腕/髋部可见且手腕偏低时，建议尝试手部落点；较大脸部转角时提供另一种版本 | 坐姿、遮挡、透视会影响二维判断；一般的放松肩膀提示明确标为创作建议。 |
| 表情 | 用户选的自然、安静、轻快 | 是引导语，没有识别情绪、评价容貌或判断当前表情“错误”。 |
| 光线 | 平均亮度、暗部比例、接近白色的采样比例 | 可提醒检查暗调或亮部，不能确定太阳方向、脸部受光、真实动态范围或 RAW 过曝。 |
| 风光 | 用户选的三分、对称、前景方案与手动标记水平线 | 目前没有识别天空、山峰、道路、建筑、倒影和空间可行走区域；风光建议多数仍是模板。 |

新版优先呈现检测故障、明显亮度问题和构图，再提供动作/表情。一般光线提示不再总占据第一位。界面一次显示一个类别的建议，使用“画面测量 / 创作建议”标识，点击可查看证据与来源。“画面测量”代表触发条件有检测依据，不代表建议已经获得审美模型验证。

现有书籍、公开教材和比赛资料是规则的知识来源与研究入口，**不等于已经读完全文，也不等于已训练进模型**。

## 是否要训练模型

要让 App 理解复杂背景并在多个构图之间作选择，视觉模型值得投入；本次稳定检测和 UI 问题则无需重新训练。

建议顺序：

1. 先接入可部署的预训练主体/背景分割模型，验证人像占比、头顶留白、背景遮挡、天空与地面等可测特征。模型选型要实测 K80 的延迟、内存、温升及功耗。
2. 在当前画面内生成多个裁剪/构图候选，由审美排序模型比较；同时允许用户指定主角与意图。裁剪框能提示取景范围，不能直接换算成“走两步”或真实光源方向。
3. 人物动作建立有适用条件的动作库：站姿/坐姿、全身/半身、关节可见性等。缺少可靠关键点时只给可选示范，不作姿态诊断。
4. 有数据后再微调排序与推荐模型。训练样本应包含：同一场景的多个取景、明确主角/拍摄意图、摄影师的成对偏好与理由、建议是否被采用、调整前后结果。获奖单张图通常缺少失败对照和拍摄过程，不能单独提供“该怎样改”的监督。

**本次没有启动模型训练或新增后台采集。** 后续收集照片需要用户主动选择与明确同意，核对图片、人物及数据集的使用许可；公开可下载不等于可商用训练。

验证分开进行：稳定门控测进入延迟 P50/P95、3 秒内进入率、轻微手抖误重置率、真实换景撤回延迟；建议质量做盲测，比较原版、规则新版与模型候选，记录摄影师/用户偏好。训练与评估按场景、人物和设备隔离，避免同一场景的相似图泄漏。不能只用模型自己的审美分数证明改善。

## 已核实的一手研究入口

- [ML Kit Pose Detection 官方文档](https://developers.google.com/ml-kit/vision/pose-detection)：模型给关键点位置，本身不给动作含义或美学判断。
- [SACD 官方项目](https://cg.cs.tsinghua.edu.cn/SACD/)：围绕指定主体的构图裁剪与排序数据，是构图排序方向的参考；采用前仍需核对许可。
- [ProCrop 论文](https://arxiv.org/abs/2505.22490)：研究利用专业摄影构图改善图像裁剪；不能据此声称已实现现场机位或人物动作指导。

上面是研究与后续架构建议，当前 APK 没有集成 SACD 或 ProCrop 模型。
