# 0.4 分步拍摄向导

本版将[产品与方法调研](PHOTOGRAPHY_ASSISTANT_RESEARCH.md)中的拍摄意图、主体条件和分步指导接入 Android App。实现使用端侧检测和原创规则，没有新增云端视觉调用或模型训练。

## 如何使用

1. 在人像模式选择「突出人物」或「人物与环境」；在风光模式选择「突出天空」「突出地景」或「自由观察」。人像氛围和构图仍可手选。
2. 稳定取景约 2.5 秒后，默认显示「本次指导」。多人时在预览中点选人脸框；追踪编号只用于本次取景，不是身份识别。主角丢失时停止指导，不切换到剩下的人。
3. 按当前卡片操作。卡片标明「拍摄者 · 调整取景」「人物 · 尝试动作」或「拍摄者 · 观察确认」。取景方向表示主角在手机预览中应移动的方向，不表示人物本人应该向哪边走，也不表示摄影者应向哪边走多少米。
4. 点击「已确认」进入下一步；不适用时「跳过」；「撤回上步」回到上一项。撤回只恢复指导步骤，不修改已拍照片。自动测量不替用户确认完成。
5. 点击「画面观察」查看测量、手选条件和未知项。风光可点击预览标记水平线；调整手机后需重新标记。没有清晰水平线可跳过。
6. 姿势库仍可筛选、收藏和锁定。选定动作后，本次指导按「背景关系—动作—目光」逐步提示；「姿势」页保留单人手臂参考。

界面重建后保留手选拍摄意图，清除当次主体选择和步骤。持续移动导致重新取景、切换镜头、模式、切后台或手动重新观察时撤回现场指导。当前稳定算法不能可靠区分刻意调整取景与真正换到另一个地点，所以持续调整手机也可能重置本次指导；意图保留。改变构图、氛围或动作会重新生成步骤。

## 依据与推荐边界

| 输入 | 本版用途 | 不代表的能力 |
| --- | --- | --- |
| 人脸位置、框宽高和临时追踪编号 | 单人或点选主角、预览中位置参考、人脸框面积与上缘 | 全身占比、头发边界、真实身份、目光方向或情绪 |
| 预览亮度、近白采样比例及独立时间戳 | 提醒检查亮区或暗调 | RAW 过曝诊断、脸部局部曝光、太阳或灯具方向 |
| 构图与拍摄意图 | 原创三分或居中参考、环境保留的观察任务 | 三分法最优、自动理解背景内容、审美评分 |
| 手动水平线 | 给天空或地景分配画幅的可选步骤 | 自动地平线检测、地平线倾斜测量 |
| 姿势卡与氛围 | 原创动作和目光引导脚本 | 判断当前动作是否优美、动作一定适合环境 |

几何结果超过 1.2 秒、来自旧相机会话、主角丢失或检测失败时，不展示有效人物目标，也不允许确认旧步骤。亮度和人物检测有独立时间戳；风光没有人脸结果也可工作。一次只提示一个取景轴；目标位置接近后保留当前步骤，请用户确认，不自动声称照片变好。

没有可依据的取景调整时，进入明确标为创作建议的观察或动作任务；完成或跳过这些任务后显示「暂未找到可确认的新改进」。不为了给建议而持续要求移动。「动作」「表情」分类保留为用户主动浏览的创作参考，不作为点选主角的自动诊断。

本版未接入背景语义模型、自动场景道具检测、太阳规划、实时语音或照片盲评界面。尚未审核的 129 个视频案例仍不进入训练。下一步应先收集有权限的同场景调整前后照片及摄影者偏好，核对人物关联、建议适用性与实际拍摄效果，再评估视觉模型。

## 坐标与验证

人物测量继续使用 CameraX 的 `COORDINATE_SYSTEM_VIEW_REFERENCED`，与屏幕预览及叠图共用坐标；保留精确帧时间戳、尺寸和会话校验。CameraController 管理预览与拍摄用例，[CameraX 官方架构](https://developer.android.com/media/camera/camerax/architecture)说明了其用例和生命周期管理。本版增加相机测试，读取保存 JPEG 的尺寸和 EXIF 旋转，与实际 PreviewView 的画幅比例比较。画幅相同仍不能证明每个像素在所有真机、镜像和横竖屏情况下完全对齐。

新增核心测试覆盖主角选择、主角丢失、过期与旧会话、步骤确认/跳过/撤回、意图、动作脚本、无依据时不强行调整、手动水平线和方向约定。新增模拟器测试检查实际页面操作、意图持久化、重建清除步骤与事实说明。实际执行结果和限制记录在[验证记录](VERIFICATION.md)。红米 K80 的拍摄质量、多人关联、发热和提示延迟仍需真机验收。
