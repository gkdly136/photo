# 真机验收清单

以下项目不能用编译成功或合成演示测试替代。至少选择一台 Google 设备和两台国产品牌设备，记录系统、SoC、相机模式、推理耗时、温度与电量。

- Android 10/12/14/15：首次允许、拒绝、永久拒绝与系统设置后再授权。
- 前后镜头、竖屏、横屏、旋转屏幕：人脸框/骨架与真人重合；目标线与保存照片的构图一致；前置左右方向明确。
- 相机被占用、不可用或没有前置镜头：显示错误，不崩溃；可返回演示。
- 停留 2/2.5/3 秒：触发时间正确；静止场景不重复触发；快速和缓慢平移、旋转后撤下旧建议。
- 三脚架对准背景，人物在中央活动：尽量不重置背景停留；人物移动到边缘时记录误触发率。
- 树叶、水面、夜景和白墙：确认保守反馈；不能把“未发现变化”当成完整理解场景。
- 无陀螺仪机型：帧差降级仍能使用，记录无纹理背景的局限。
- 单人、多人、远处小脸、侧脸、遮挡、不同肤色与体型：低置信度关键点不用于具体动作判断。
- 坐姿、轮椅、半身照：模板建议可忽略，避免要求不舒适动作；后续加入姿态偏好选项。
- 5 分钟与 20 分钟连续预览：记录耗电、温升、P50/P95 延迟与预览掉帧。
- 息屏、回桌面、应用切换、来电、旋转和进程重建：相机释放，旧建议清除，检测正常恢复。
- 原片拍照成功并可在系统相册查看；照片没有辅助线，Exif 方向正确；存储空间不足有失败反馈。
- 辅助线开关、构图切换、表情选项、手动水平线与来源链接均可操作。
- 字体放大、窄屏和 TalkBack：控件可读、建议可滚动、操作不遮挡主取景。

下一阶段再增加外接相机兼容测试，当前不宣称支持外接实时流。

## 0.4 分步向导复测

1. 人像选择「突出人物」与「人物与环境」，风光选择天空、地景和自由观察，核对指导与意图一致。旋转屏幕后保留意图，清除本次步骤。
2. 多人分别点选较小、较大人脸，确认不会按面积替换主角；遮挡所选主角、让主角离开再回来，确认暂停和恢复。临时追踪不代表身份识别，交叉遮挡时重点记录误关联。
3. 对同一步分别确认、跳过、撤回，确认不会重复推进或清零稳定等待。改构图、氛围、姿势和持续移动后应撤回旧现场指导。
4. 前后镜头分别检查取景指令：方向指主角在预览中应向哪边移动；人物保持原位，只调整手机。一次只提示一个轴。
5. 打开画面观察，核对人脸框面积和上缘不是全身占比和头发边界。背景、光源方向和情绪应明确为尚未识别。
6. 在风光点击水平线，选择突出天空/地景；移动取景后重新标记，避免用旧坐标假装追踪地平线。无地平线可跳过。
7. 分别拍摄竖屏、横屏、前后镜头照片，比较预览画幅、JPEG 实际方向与边缘内容；相同宽高比不能代替像素对齐验证。
8. 完成或跳过所有步骤，应允许直接拍照并显示暂无新改进，不能为了触发完成而要求无限调整。分别盲看调整前后照片，记录偏好与理由，不能把已确认步骤数当作摄影质量。

## Redmi K80 本轮复测

本轮已确认用户机型为 Redmi K80；尚无该机的传感器实测记录。不要把模拟测试描述为 K80 真机通过。

1. 在普通室内、室外静态背景各手持 10 次，默认 2.5 秒；记录从停止主动移动到进入辅助的时间，目标大多数在 3 秒左右进入。
2. 保持背景，在自然呼吸、轻微手抖、按侧键音量时观察：进度不应反复归零；单次短促扰动允许暂停。
3. 建议出现后快速换景、缓慢横移、缓慢旋转、对准白墙旋转：旧建议应在确认移动后撤下，停住后重新计时。
4. 未进入辅助时点击「立即辅助」应立即使用最新已读帧，状态明确为手动请求；换景仍撤下旧提示。
5. 前后镜头、横竖屏、2/2.5/3 秒设置、类别切换、字体放大与拍照保存各试一次。
6. 记录 HyperOS / Android 版本、镜头、环境及异常出现概率。后续只有主动导出并同意提供时，才采集诊断或照片。

## 0.3 姿势参考复测

1. 打开「姿势库 · 40」，分别选择站、坐、靠、轻动作以及全身、半身、正面、斜侧。坐姿未确认有座椅、靠姿未确认有墙面时，应显示空状态，不推荐不满足条件的动作。
2. 收藏一个动作，重新打开应用后检查收藏仍在；本次锁定的目标应在切后台或重新观察后撤回。改变拍摄条件，确认不适用的目标会清除。
3. 锁定左手扶腰或抬手，人物改变动作时目标保持。前后镜头下确认「人物自己的左手」一致；涉及画面左右的提示应随预览镜像正确变化。
4. 对照不同肩宽、躯干比例和站位远近，不应把体型不同当作错误。检查腿部与手指不参与「手臂已接近参考」的判断。
5. 半身、缺失手腕、双臂遮挡、背身、多人、暗光和小人脸：只提供参考，不画无依据的目标手臂。动态与双手身后动作始终只作示范。
6. 快速换景、镜头切换、横竖屏和主角更换时，旧目标及旧关节提示撤回。恢复画面后需要新帧连续支持，不能把旧测量重新显示为有效。
7. 打开目标手臂虚线，确认其与当前骨架颜色可区分、指向正确，关闭辅助线后隐藏。拍照原片不得含线稿、目标或测量点。
8. 记录提示出现时间、错误方向、提示跳变、主角误关联和温升。先验证少量站姿和半身动作的自然度，再扩大使用，不以模拟器通过替代 K80 真机校准。
