# 观景 · FrameCoach

一个给业余摄影爱好者的 **Android 原生辅助取景 App**。

将手机对准场景，保持约 2 秒，App 会显示构图参考线、人物目标位置，以及光线、动作和表情提示。你可以选择不同方案，而不是被一个审美分数限制。

## 首版功能

- CameraX 实时取景，支持前后镜头和相册拍照保存；辅助线不写入原片。
- 画面变化 + 陀螺仪判断取景是否稳定，停留时间可选 2 / 3 / 5 秒。
- 检测到移动时撤下旧建议；稳定后重新生成，同一静止场景不会反复触发。
- ML Kit 端侧人脸位置、头部转角、人体关键点分析，低置信度关键点不用于姿态判断。
- 人像：三分法或居中站位参考，动作与用户选择的「自然 / 安静 / 轻快」表情方向。
- 风光：三分、对称或前景层次方案，点击画面**手动标记**水平线。
- 预览亮度与明暗分布检查；不把预览白色区域等同于 RAW 已过曝。
- 来源卡片解释每条提示的证据、适用条件和局限。
- 无需相机权限即可体验明确标识的合成演示场景。

## 安装和构建

最低 **Android 10 / API 29**。不需要账号、服务器或 API Key。

1. 用 Android Studio 打开项目目录。
2. 安装 Android SDK Platform 35、Build Tools 35.0.0，使用 JDK 17。
3. 完成 Gradle 同步，运行 `app` 到手机，或构建 Debug APK。

命令行需要 Gradle 8.11.1：

```shell
gradle :core:test :app:lintDebug :app:assembleDebug
```

APK 路径：`app/build/outputs/apk/debug/app-debug.apk`。

仓库 Actions 中的 **Android build and tests** 会运行单元测试、Lint、APK 构建和 Android 模拟器演示测试。成功后的 APK 位于 `framecoach-debug-and-reports` 附件中，下载 ZIP 后解压安装 APK。附件保留 30 天，需要登录 GitHub 下载。

当前代码和实际验证状态以 [验证记录](docs/VERIFICATION.md) 为准。Debug APK 仅用于试用；上架前需要签名与完整真机测试。

## 使用

1. 初次进入显示合成演示。点击「开启相机」并授予权限。
2. 选择「人像」或「风光」，稳住镜头，等待进度条走满。
3. 调整构图方案；人像可选择想拍出的感觉。绿色圆圈是可尝试的人脸落点，不是必须达到的标准。
4. 点开任意建议，查看依据、限制和原始知识来源。
5. 点击「拍照」，原片保存到相册 `Pictures/FrameCoach`。

人物移动到画面边缘、树叶/水面变化、极暗或纹理不足的背景，可能影响稳定判断。人像模式主要观察画面边缘以减少中央人物动作的干扰。没有陀螺仪的设备仅使用画面变化。

## 知识与能力边界

首版依据公开出版社书目、Scott Kelby 的出版社公开节选、Nikon 教学、RISD 课程说明、MoMA 摄影教育资源和 Sony 摄影比赛官方资料整理原创规则。用户已确认三本书的作者；已核实斯蒂芬·肖尔、本·克莱门茨与 David Rosenfeld 的英文书目，并找到 Scott Kelby 的风光摄影公开节选。**没有通读三本书全部正文，也没有完成各大院校教材和所有获奖作品的学习。** 中文具体版本尚待核对。

获奖作品目前仅为研究入口，未逐幅完成视觉标注，未抓取原图、复制图册或用于训练。规则库不是训练后的摄影大模型。

当前模型能检测人脸和关键点，不能完整理解故事、自动找到最美背景、测量真实光源方向、恢复三维可行走空间、识别人的情绪，或控制外接单反/微单。后续接入相机实时流需要逐型号验证厂商 SDK 或兼容采集设备。

详见 [产品方案](docs/PRODUCT.md)、[摄影资料与知识库](docs/RESEARCH.md)、[隐私说明](docs/PRIVACY.md) 和 [真机验收清单](docs/DEVICE_TEST_PLAN.md)。

## 代码结构

```text
app/                         Android 界面、相机、端侧模型和取景叠加
core/                        不依赖 Android 的稳定判断与建议引擎
core/src/test/               稳定时序、慢速平移、曝光变化与建议边界测试
app/src/androidTest/         演示场景、模式切换和重建测试
docs/                       知识来源、产品边界、隐私与验收
.github/workflows/           自动构建与模拟器测试
```

CameraX 1.5.3、ML Kit Face 16.1.7、Pose 18.0.0-beta5；人体姿态 SDK 仍为 Beta，需要重点测试设备兼容性。模型打包进 APK，首次使用不需要另行下载模型。ML Kit 自身可能收集 SDK 诊断或使用信息，参见隐私说明。
